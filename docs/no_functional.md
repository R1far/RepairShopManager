# Нефункциональные требования

1. **Простота использования**
   - Интерфейс должен быть понятен без обучения
   - Все основные действия доступны в 2-3 клика

2. **Безопасность**
   - Доступ только для зарегистрированных пользователей
   - Защита регистрации кодом доступа
   - Разграничение прав мастеров и администраторов

3. **Производительность**
   - Быстрая загрузка списков
   - Быстрый поиск по базе данных
