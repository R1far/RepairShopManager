# Техническое задание

**Зачем нужно приложение:**
Чтобы навести порядок в мастерской: быстро записывать клиентов, следить за остатками запчастей на складе, не путаться в ценах и видеть историю ремонтов.

**Основные функции:**
* **Заказы:** оформление заявок, выбор услуг и контроль готовности.
* **Склад:** учет деталей и их автоматическое списание при использовании.
* **Управление:** настройка цен и прав доступа для сотрудников.

**Кто пользуется:**
* **Приемщики:** записывают данные и выдают технику.
* **Мастера:** отмечают выполненную работу и потраченные запчасти.
* **Руководители:** следят за процессом и меняют прайс-лист.

# Обоснование выбора стека технологий

* **Android (Java):** Приложение будет работать на большинстве смартфонов (от Android 7.0 и выше). Это надежный стандарт, который гарантирует стабильность.
* **Firebase Firestore:** Облачная база данных. Сотрудники видят все изменения мгновенно. Главный плюс — работа без интернета: данные сохраняются в телефоне и отправляются в облако, как только появится сеть.
* **Firebase Authentication:** Надежный сервис для входа в систему. Мастера заходят под своими логинами и паролями, а данные защищены.
