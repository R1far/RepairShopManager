# Функциональные требования

## Модуль 1: Аутентификация (AUTH)

| Функция | ID | Описание | Статус | Доступ |
| :--- | :--- | :--- | :--- | :--- |
| **Авторизация (Вход)** | AUTH-001 | Вход в приложение с использованием Email и Пароля. | Реализовано | Гость |
| **Регистрация** | AUTH-002 | Создание учетной записи. Пользователь вводит ФИО, Email, Пароль и Код доступа. | Реализовано | Гость |
| **Проверка кода доступа** | AUTH-003 | При регистрации система сверяет введенный код с текущим значением в Базе Данных. Если код не совпадает — регистрация блокируется. | Реализовано | Система |
| **Присвоение роли** | AUTH-004 | При регистрации через приложение пользователю автоматически присваивается роль «Мастер». Роль «Администратор» назначается вручную через БД. | Реализовано | Система |

## Модуль 2: Системные настройки (SET)

| Функция | ID | Описание | Статус | Доступ |
| :--- | :--- | :--- | :--- | :--- |
| **Смена кода регистрации** | SET-001 | Поле ввода для изменения текущего "Кода доступа" мастеров. Новое значение сохраняется в БД. | Реализовано | Админ |
| **Просмотр текущего кода** | SET-002 | Отображение действующего кода на экране (чтобы владелец мог скопировать и отправить новому сотруднику). | Реализовано | Админ |


## Модуль 3: Управление заказами (ORD)

| Функция | ID | Описание | Статус | Доступ |
| :--- | :--- | :--- | :--- | :--- |
| **Список заказов** | ORD-001 | Отображение списка всех активных ремонтов (ID, Объект, Клиент, Статус). | Реализовано | Все |
| **Создание заказа** | ORD-002 | Оформление нового ремонта. Поле "Мастер" заполняется автоматически текущим пользователем. | Реализовано | Все |
| **Поиск заказа** | ORD-003 | Фильтрация списка по номеру телефона, фамилии или модели. | Реализовано | Все |
| **Редактирование заказа** | ORD-004 | Изменение описания поломки, услуг и запчастей. | Реализовано | Все |
| **Смена статуса** | ORD-005 | Переключение этапов ("Новый" - "В работе" - "Готов" - "Выдан"). | Реализовано | Все |
| **Смена мастера** | ORD-006 | Возможность назначить другого сотрудника ответственным за заказ. | Реализовано | Все |
| **Итоговый расчет** | ORD-007 | Автоматическое формирование финальной суммы заказа на основе цен запчастей и услуг. | Реализовано | Система |

## Модуль 4: Управление складом (STK)

| Функция | ID | Описание | Статус | Доступ |
| :--- | :--- | :--- | :--- | :--- |
| **Просмотр склада** | STK-001 | Отображение списка запчастей (Артикул, Название, Кол-во, Цена). | Реализовано | Все |
| **Поиск товара** | STK-002 | Фильтрация по названию или артикулу детали. | Реализовано | Все |
| **Создание товара** | STK-003 | Добавление новой карточки запчасти (если такой раньше не было). | Реализовано | Все |
| **Оформление прихода** | STK-004 | Увеличение количества товара (ввод числа поступивших деталей). | Реализовано | Все |
| **Автосписание** | STK-005 | Автоматическое уменьшение остатка на складе при добавлении детали в Заказ. Блокировка, если товара < 1 | Реализовано | Система |
| **Редактирование товара** | STK-006 | Изменение названия или цены запчасти. | Реализовано | **Только Админ** |
| **Удаление товара** | STK-007 | Полное удаление карточки товара из базы данных. | Реализовано | **Только Админ** |
| **Возврат на склад** | STK-008 | Автоматический возврат товара, если запчасть удалена из заказа или заказ отменен. | Реализовано | Система |

## Модуль 5: Управление услугами и ценами (SRV)

| Функция | ID | Описание | Статус | Доступ |
| :--- | :--- | :--- | :--- | :--- |
| **Просмотр стоимости** | SRV-001 | Отображение списка услуг и их фиксированной стоимости. | Реализовано | Все |
| **Поиск услуги** | SRV-002 | Поиск работы по названию для быстрого добавления в заказ. | Реализовано | Все |
| **Добавление услуги** | SRV-003 | Создание новой позиции в справочнике цен. | Реализовано | **Только Админ** |
| **Изменение цены** | SRV-004 | Редактирование названия или стоимости услуги. | Реализовано | **Только Админ** |
| **Удаление услуги** | SRV-005 | Удаление позиции из прайс-листа. | Реализовано | **Только Админ** |
