# Описание макетов

## Описание интерфейса - Вкладка «Заказы»

### Список заказов
Вкладка «Заказы» (Рисунок №1) управляется через панель «btnSearch» для поиска и фильтрации записей. Данные выводятся в основной контейнер «containerOrders», предназначенный для отображения списка активных и завершенных заказов.

### Добавления заказа
Карточка заказа (Рисунок №2) содержит поля для ввода основной информации: «etRepair» для описания ремонтируемого устройства, «etFIO» для ФИО клиента, «etPhone» для контактного телефона и «etBreaking» для описания заявленной неисправности. Поле «etMaster» указывает на ответственного сотрудника.
«addServices» для добавления услуги и «addSparePart» для списания использованных запчастей. Итоговая сумма рассчитывается автоматически и отображается в поле «Result». Подтверждение создания или изменений происходит по нажатию кнопки «btnSave».

### Элемент списка
Отдельная запись в списке заказов (Рисунок №3) содержит ключевые идентификаторы: артикул «txtArticle» и текущий статус выполнения «status». Также отображается основная информация для быстрого просмотра: объект ремонта «objectOfRepair», данные клиента «FIO» и «phone». Финансовая информация представлена полем «price», а краткая сводка по материалам — полем «details|spareParts».

## Описание интерфейса - Вкладка «Запчасти» (Склад)

### Список запчастей
Вкладка управления складом (Рисунок №4) оснащена панелью «btnSearch» для быстрого поиска необходимых деталей по названию или артикулу. Результаты поиска и весь перечень доступных товаров выводятся в область «containerSpareParts».

### Форма запчасти
Форма добавления или редактирования товара (Рисунок №5) включает следующие поля ввода:
- «txtArticle» — для указания уникального артикула детали.
- «Name» — для ввода наименования запчасти.
- «quantity» — для указания текущего остатка на складе.
- «Price» — для установки стоимости за единицу.
Фиксация внесенных данных осуществляется нажатием кнопки «btnSave».

### Элемент списка
Карточка товара в общем списке (Рисунок №6) отображает ключевую информацию для инвентаризации:
- «txtArticle» — артикул для быстрой идентификации.
- «nameSparePart» — полное наименование детали.
- «quantity» — доступное количество.

Интерфейс добавления или изменения услуги (Рисунок №8) состоит из следующих элементов управления:

## Описание интерфейса - Вкладка «Архив» (История)

### Список архива
Вкладка истории заказов (Рисунок #10) структурно повторяет основной список заказов. Панель «btnSearch» используется для поиска по базе завершенных работ. Результаты выборки отображаются в контейнере «containerOrders», который содержит список закрытых или отмененных заказов.

## Описание интерфейса - Вкладка «Персонал»

Верхняя часть экрана (Рисунок №11) предназначена для настройки кодов доступа. Поле «Code» позволяет задать или изменить текущий код регистрации для новых сотрудников. Сохранение изменений выполняется кнопкой «btnSave».
Основная рабочая область управляется панелью поиска «btnSearch». Карточки сотрудников выводятся в контейнер «containerPersonal», отображая список зарегистрированных пользователей системы.
