# Тест-кейсы для модульного тестирования

### Таблица 1. Тестирование валидации ФИО
**Класс:** `ValidationUtils`  
**Метод:** `isValidFullName`  
**Описание:** Проверка корректности ввода полного имени пользователя.

| ID | Цель | Входные данные | Ожидаемый результат |
|:---|:---|:---|:---|
| 1 | Проверка корректного ФИО | Имя: `"Иван Иванов"` | Метод возвращает `true` (Имя корректно) |
| 2 | Проверка ФИО с цифрами | Имя: `"Иван 1"` | Метод возвращает `false` (Имя не должно содержать цифр) |
| 3 | Проверка слишком короткого имени | Имя: `"Я"` | Метод возвращает `false` (Минимум 2 символа) |

### Таблица 2. Тестирование валидации Email
**Класс:** `ValidationUtils`  
**Метод:** `isValidEmail`  
**Описание:** Проверка формата электронной почты.

| ID | Цель | Входные данные | Ожидаемый результат |
|:---|:---|:---|:---|
| 1 | Проверка корректного email | Email: `"user@gmail.com"` | Метод возвращает `true` (Формат верный) |
| 2 | Проверка email без символа @ | Email: `"usergmail.com"` | Метод возвращает `false` (Отсутствует обязательный символ @) |
| 3 | Проверка пустого поля | Email: `""` | Метод возвращает `false` (Поле не может быть пустым) |

### Таблица 3. Тестирование валидации пароля
**Класс:** `ValidationUtils`  
**Метод:** `isValidPassword`  
**Описание:** Проверка сложности пароля (длина).

| ID | Цель | Входные данные | Ожидаемый результат |
|:---|:---|:---|:---|
| 1 | Проверка пароля нормальной длины | Пароль: `"password123"` | Метод возвращает `true` (Длина > 6 символов) |
| 2 | Проверка короткого пароля | Пароль: `"12345"` | Метод возвращает `false` (Длина < 6 символов) |
| 3 | Проверка null значения | Пароль: `null` | Метод возвращает `false` (Пароль не может быть null) |

### Таблица 4. Тестирование расчета стоимости
**Класс:** `Order`  
**Метод:** `calculateTotal`  
**Описание:** Проверка суммирования стоимости услуг и запчастей в заказе.

| ID | Цель | Входные данные | Ожидаемый результат |
|:---|:---|:---|:---|
| 1 | Расчет полной стоимости | Услуги: цена: 1000 <br>Запчасти: цена: 300 | Метод устанавливает `totalPrice = 1300.0` |
| 2 | Расчет стоимости без запчастей | Услуги: цена: 2000<br>Запчасти: 0 | Метод устанавливает `totalPrice = 2000.0` |
| 3 | Расчет для пустого заказа | Услуги: 0<br>Запчасти: 0 | Метод устанавливает `totalPrice = 0.0` |
