
## Навигация по документации

Ниже представлены основные разделы проектной документации. Вы можете перейти к любому файлу для детального изучения:

### Проектирование и Анализ
* **[Описание предметной области](docs/domain_analysis.md)** — анализ ключевых процессов: от приема устройства до управления персоналом и складских операций.
* **[Техническое задание](docs/terms_of_reference.md)** — цели разработки, стек технологий (Java, Firebase) и описание целевой аудитории.
* **[Диаграмма вариантов использования](docs/use_case_diagram.md)** — визуализация взаимодействия субъектов (Мастер, Администратор) с системой.
* **[Описание прецедентов](docs/precedents.md)** — подробные сценарии регистрации, создания заказов и выдачи устройств.

### Интерфейс и Функционал
* **[Функциональные требования](docs/functional.md)** — полный перечень функций системы (AUTH, ORD, STK, SRV) с указанием уровней доступа.
* **[Нефункциональные требования](docs/no_functional.md)** — стандарты безопасности, производительности и удобства интерфейса.
* **[Описание макетов](docs/layout.md)** — визуальное руководство по интерфейсу с пояснением экранных форм и элементов управления.

### Тестирование
* **[Модульное тестирование](docs/unit_testing.md)** — тест-кейсы для валидации данных (Email, ФИО, пароли) и логики расчета стоимости.
* **[Интеграционное тестирование](docs/integration_testing.md)** — граф программы, пути навигации и проверка связей между модулями Склад ↔ Заказы.
